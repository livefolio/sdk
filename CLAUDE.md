## Project Conventions

- **ES Modules**: All imports use `.js` extensions (`import { Foo } from './foo.js'`)
- **Strict TypeScript**: `strict: true`, `noUncheckedIndexedAccess: true`
- **Tests**: Co-located `*.test.ts` files, run with `npm test` (Vitest)
- **Formatting**: Prettier on save, ESLint with typescript-eslint rules
- **Pre-commit**: Husky + lint-staged runs `eslint --fix` and `prettier --write` on staged `.ts` files

## Key Commands

| Command | Purpose |
|---------|---------|
| `npm test` | Run all tests |
| `npm run build` | Compile TypeScript to `dist/` |
| `npm run lint` | Check ESLint rules |
| `npm run lint:fix` | Auto-fix ESLint issues |
| `npm run format` | Format with Prettier |
| `npm run format:check` | Check formatting |

## Do Not

- Edit `src/database.types.ts` — auto-generated by `supabase gen types`
- Modify applied Supabase migrations — create new ones instead
- Add real database calls in unit tests — mock Supabase with `vi.fn()`
