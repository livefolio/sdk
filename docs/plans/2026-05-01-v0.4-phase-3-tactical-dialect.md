**Goal:** Land the v0.4 tactical dialect as **`tactical/v0`** (provisional — see "Versioning" below) — `TacticalSpec` types, `evaluateRuleTree`, `evaluateFeatureSpecs`, `withSynthetics`, and `fromSpec` — so a JSON spec describing universe + rebalance cadence + per-asset features (with optional delay) + a comparison-driven rule tree (with optional hysteresis bands) + optional leveraged synthetic assets (with optional expense drag and live-routing seam) hydrates into a `Strategy<F>` that runs end-to-end through `runBacktest`.

**Architecture:** Phase 3 lives in **one new top-level module** that does not collide with v0.3 or earlier v0.4 phases:

- `src/tactical/` — dialect types, rule-tree evaluator, feature-spec resolver, synthetic-asset DataFeed wrapper, `fromSpec` hydrator.

`fromSpec` returns a v0.4 `Strategy<{ values, prices }>` whose `build` is `reconcile(evaluateRuleTree(rules, values, state), portfolio, prices)` on rebalance days, `[]` otherwise. The user serializes the *inputs to the pattern* (universe, synthetics, rebalance cadence, feature specs, rule tree); the SDK ships the pattern itself. No mutation of phase 1 or 2 modules; no public-API change in `src/index.ts`.

**Versioning — `tactical/v0` not `v1`.** v1 commits to wire-format stability. We don't have parity proof yet (phase 5). Stamping v1 now and discovering in phase 5 that we need to rename a field forces us into `v2` with a deprecation window we shouldn't owe ourselves. v0 says "expect breaking changes; do not persist these specs in production yet." Phase 5's parity test against a real v0.3 strategy is the gate for promoting v0 → v1.

**Five additive capabilities folded in (vs. the v0.4-spec sketch):**

1. **Hysteresis on comparisons** — `Comparison.tolerance?` band + required `Comparison.id` when tolerance is set; `evaluateRuleTree` becomes stateful (`(rules, values, state?) → { weights, state }`); `fromSpec` closes over the state map across `t`.
2. **Per-feature delay** — additive `TacticalFeatureSpec.delay?: number` (sessions). Applied in `evaluateFeatureSpecs` as a positional shift after `runtime.compute` and before `seriesAt`. Phase-2 cache stays unchanged (delay is a cheap post-transform on read).
3. **Leveraged synthetic assets with expense drag** — additive `TacticalSpec.synthetics?: SyntheticAsset[]` with optional `expense?: number` (annualized). Implemented as a `withSynthetics(dataFeed, synthetics): DataFeed` wrapper that synthesizes bars from the underlying's daily returns + leverage compounding − daily expense.
4. **Rebalance cadence** — `TacticalSpec.rebalance?: { frequency }` covering `Daily`/`Weekly`/`Monthly`/`Quarterly`/`Yearly`. Default `Daily` (every session). On non-rebalance sessions, `build` returns `[]` and **does not advance hysteresis state**. `fromSpec` accepts a `Calendar` to compute period boundaries.
5. **Synthetic → tradeable routing seam (reserved, no-op in v0)** — `SyntheticAsset.tradeAs?: AssetRef`. Phase-3's `BacktestExecutor` ignores it; orders fill against synthetic bars (the modeling backtest). Phase 4+ executors honor it for live routing. Reserved now to avoid a future breaking change.

**Tech Stack:** TypeScript (strict, `noUncheckedIndexedAccess: true`), ES modules with extensionless imports, Vitest, tsup, Prettier, ESLint.

**Out of scope for this phase:**
- **Rebalance offset** (e.g. "second-to-last session of the month"). v0 ships `frequency` only; offset is a v0.3 feature almost no one uses outside `Daily` / EOM. Add as `rebalance.offset?: number` in a future minor version when a real consumer needs it.
- **`manage` / `scan` / `overlay` strategy helpers.** Tactical strategies use `reconcile` only; the helpers ship with the second strategy family that needs them.
- **Multi-input feature kinds** (Bollinger / ATR / VWAP) — phase 2 already deferred these; tactical/v0 inherits the close-only single-input set.
- **JSON schema validator** (`assertTacticalSpec`). Phase 3 is consumed in code form; phase 4 / 5 will add validation when JSON ingest matters.
- **`tactical/v1`** (the stable bump) and any non-tactical dialect (`riskparity/v0`, `xs-momentum/v0`, …). One dialect, one version, provisional.
- **`composite/v0` dialect** — deferred until the second dialect ships.
- **Borrow / financing on actual short positions.** Synthetic-asset `expense` (annualized drag) is in scope. Modeling overnight short-borrow costs on real `OpenOrder { side: 'short' }` positions is an executor / portfolio concern, not a dialect concern. v0.3's `rate-ticker-financing` reintroduction in v0.4 is a separate spec evolution.
- **Live execution routing** (`SyntheticAsset.tradeAs?` is reserved but no-op in v0). Phase-3's `BacktestExecutor` fills synthetic orders against synthetic bars. A live-trading executor that honors `tradeAs` is phase-4+.
- **Synthetic asset execution semantics beyond `nextOpen`.** Synthetic bars set `open = high = low = close = synthClose` so `BacktestExecutor.nextOpen` works; partial fills, slippage modeling on inverse / leveraged ETFs are not modeled specially.
- **Public API switch in `src/index.ts`.** v0.3 continues to ship; v0.4 modules co-exist.
- **v0.3 codemod and parity test** — phases 4 / 5 / 6 (parity is also the gate for `tactical/v0` → `tactical/v1`).


Naming conventions: kebab-case file names for multi-word (matching phase 1/2 — `run-backtest.ts`, `series-utils.ts`); co-located `*.test.ts`; module barrel via `index.ts`. The `src/tactical/` directory mirrors the v0.4 spec § Module map entry one-to-one.

Conventions: ES module imports are extensionless, `strict: true` plus `noUncheckedIndexedAccess: true` mean every Map `.get()` and array index produces `T | undefined` and must be narrowed. Tests use Vitest's `vi.fn()` for mocks; no Supabase, no real network.

**Two layers of "spec".** Phase 2's `FeatureSpec` (in `src/features/spec.ts`) describes per-asset feature *math* — kind + params, no asset binding (`runtime.compute(spec, asset)` receives the asset separately). Phase 3 introduces `TacticalFeatureSpec` (in `src/tactical/types.ts`) which wraps `FeatureSpec` with an `id` (referenced by rules), an `asset` (the binding the rule cares about), and an optional `delay`. The dialect spec is the user-facing layer; phase 2's `FeatureSpec` is the math layer underneath.

**Hysteresis and state.** `evaluateRuleTree` is stateful: `(rules, values, state?) → { weights, state }`. State is `ReadonlyMap<comparisonId, 0 | 1>` and only matters for comparisons that opt in via `tolerance` + `id`. Without tolerance, comparisons are pure boolean expressions and contribute nothing to state. `fromSpec` holds the state map in a closure variable that mutates each `build` call — the resulting `Strategy` is impure-by-closure (the v0.4 spec's "Strategy-level state" Open Question), but the impurity is fully encapsulated. Throwing away the strategy resets state.

**Asset resolution.** `AssetRef` is the JSON-friendly shape `{ id, symbol, exchange? }`. The dialect's `universe` is `AssetRef[]`; `fromSpec` resolves each ref to a full `Asset` (`{ kind: 'equity', id, symbol, exchange? }`) — `kind: 'equity'` is the v0.4 default and the only variant.

**Synthetic asset semantics.** A synthetic with `leverage = L`, optional annualized `expense = E`, and `underlying = U` has bars defined recurrently:
- `synth[0].close = U[0].close` (anchor)
- For `i ≥ 1`: `r_i = (U[i].close − U[i−1].close) / U[i−1].close` (treat as 0 if `U[i−1].close = 0` or non-finite); `drag = (E ?? 0) / 252`; `synth[i].close = synth[i−1].close * (1 + L * r_i) * (1 − drag)`.
- `synth[i].open = synth[i].high = synth[i].low = synth[i].close`; `synth[i].volume = U[i].volume`; `synth[i].t = U[i].t`.

This is the textbook daily-reset leveraged-ETF model. `L = 1` is the underlying; `L = -1` is the inverse; `L = 3` is 3x daily-reset. Volatility decay falls out for free; `expense` adds the multiplicative daily drag that real leveraged ETFs charge.

**Rebalance cadence semantics.** A spec with `rebalance: { frequency: F }` means: on each session `t`, `build` only emits orders if `t` is the **last session of its period under `F`**. Period keys (matching v0.3 `computeRebalanceDates`):
- `Daily` — every session is a rebalance.
- `Weekly` — last session of the ISO week (group sessions by their Thursday-anchored week number).
- `Monthly` / `Quarterly` / `Yearly` — last session of the calendar month / quarter / year.

Implementation hook: `Calendar.next(t)` is in scope (`fromSpec` accepts a `Calendar` in its options). Today is the rebalance day if `next(t)` is in a different period from `t`. On non-rebalance sessions, `build` returns `[]` and **does not advance hysteresis state** — the rule tree isn't being evaluated, so prior comparison results stay frozen.

Default (no `rebalance` field) is `{ frequency: 'Daily' }` — every session evaluates, matching the prior plan's behavior and phase-2 demo.

## Task 2: `evaluateRuleTree` — stateful rule-tree → target weights with hysteresis

**Goal:** A pure function (no IO; takes input state, returns output state) that walks a `RuleNode` against a feature-value map and produces a `TargetWeights` plus an updated state map for hysteresis. Comparisons without `tolerance` are stateless boolean expressions; comparisons with `tolerance` use the previous result (read from `state` by `comparison.id`) to decide whether the input exceeds the upper or lower band.

The signature always returns `state` so callers (e.g. `fromSpec`) can thread it across `t` without branching on whether tolerance is in use.

**Files:**
- Create: `src/tactical/evaluate-rule-tree.ts`
- Create: `src/tactical/evaluate-rule-tree.test.ts`

**Acceptance Criteria:**
- [ ] Signature:
  ```ts
  function evaluateRuleTree(
    rules: RuleNode,
    values: ReadonlyMap<string, number>,
    state?: RuleTreeState,
  ): { weights: TargetWeights; state: RuleTreeState };
  ```
  `TargetWeights` is the `ReadonlyMap<AssetId, number>` already exported by `src/strategy/reconcile.ts`.
- [ ] `allocate` node returns its `weights` as a `Map<AssetId, number>` and an empty state delta (passes input state through unchanged).
- [ ] `if` node evaluates `cond`, recurses into `then` or `else`. State updates from each evaluated branch propagate up.
- [ ] **Stateless comparison** (`tolerance` undefined): direct numeric compare. Comparison ops:
  - `gt` → `left > right`
  - `lt` → `left < right`
  - `gte` → `left >= right`
  - `lte` → `left <= right`
- [ ] **Tolerant comparison** (`tolerance` defined):
  - Throws `Error("evaluateRuleTree: comparison with tolerance requires id")` if `id` is undefined.
  - Throws `Error("evaluateRuleTree: tolerance is only supported for op gt/lt, got <op>")` if `op` is `gte` or `lte`.
  - Computes band around `right` operand: `absolute` → `[right − value, right + value]`; `relative` → `[right * (1 − value/100), right * (1 + value/100)]`.
  - Reads `prev = state.get(id)` (`undefined`, `0`, or `1`).
  - First call (`prev === undefined`): use raw boolean compare (no buffer).
  - Subsequent calls:
    - `op = gt`, `prev = 1`: stay 1 unless `left < lower`; flip to 0 when below.
    - `op = gt`, `prev = 0`: stay 0 unless `left > upper`; flip to 1 when above.
    - `op = lt`, `prev = 1`: stay 1 unless `left > upper`; flip to 0 when above.
    - `op = lt`, `prev = 0`: stay 0 unless `left < lower`; flip to 1 when below.
  - Records the result (0 or 1) into the returned state under `id`.
- [ ] Missing `FeatureRef` (id not in `values`) throws `Error("evaluateRuleTree: feature \"<id>\" has no value")`. This surfaces underflow (e.g. SMA during warmup) and typo'd refs.
- [ ] Pure: no mutation of input `values` or `state`. Returned state is a fresh `Map`.
- [ ] Tests cover:
  - Bare `allocate`, single asset
  - Bare `allocate`, empty weights → empty map
  - Stateless `if` true/else branches (literal vs ref)
  - All four ops (`gt`/`gte`/`lt`/`lte`) at the equality boundary
  - Nested `if` (3 levels deep)
  - Missing ref throws
  - Tolerant `gt` with `mode='absolute'`: first call uses raw compare; with prev=1 and value just inside upper band, stays 1; with value below lower, flips to 0; with prev=0 and value just under upper, stays 0.
  - Tolerant `gt` with `mode='relative'`: same flow but band scaled by percentage.
  - Tolerant `lt` symmetric.
  - Tolerant comparison **without** `id` throws.
  - Tolerant comparison with `op = 'gte'` throws.
  - State threading across multiple consecutive calls reproduces the v0.3 hysteresis semantics on a fixture (a sequence that would oscillate without hysteresis but stabilizes with it).

**Verify:** `npm test -- src/tactical/evaluate-rule-tree.test.ts` → all green.

```ts
import { describe, it, expect } from 'vitest';
import { evaluateRuleTree } from './evaluate-rule-tree';
import type { RuleNode, RuleTreeState } from './types';

const allocate = (weights: Record<string, number>): RuleNode => ({ op: 'allocate', weights });

describe('evaluateRuleTree (stateless)', () => {
  it('returns weights from a bare allocate node', () => {
    const out = evaluateRuleTree(allocate({ 'us:SPY': 0.6, 'us:AGG': 0.4 }), new Map());
    expect(out.weights.get('us:SPY')).toBe(0.6);
    expect(out.weights.get('us:AGG')).toBe(0.4);
    expect(out.weights.size).toBe(2);
    expect(out.state.size).toBe(0);
  });

  it('takes the then branch when comparison is true (ref vs literal)', () => {
    const rule: RuleNode = {
      op: 'if',
      cond: { op: 'gt', left: { ref: 'rsi' }, right: 70 },
      then: allocate({ 'us:SPY': 0 }),
      else: allocate({ 'us:SPY': 1 }),
    };
    expect(evaluateRuleTree(rule, new Map([['rsi', 75]])).weights.get('us:SPY')).toBe(0);
    expect(evaluateRuleTree(rule, new Map([['rsi', 50]])).weights.get('us:SPY')).toBe(1);
  });

  it('handles all four comparison ops at the equality boundary', () => {
    const at = (op: 'gt' | 'lt' | 'gte' | 'lte'): RuleNode => ({
      op: 'if',
      cond: { op, left: { ref: 'a' }, right: { ref: 'b' } },
      then: allocate({ 'us:X': 1 }),
      else: allocate({}),
    });
    const eq = new Map([['a', 5], ['b', 5]]);
    expect(evaluateRuleTree(at('gt'), eq).weights.has('us:X')).toBe(false);
    expect(evaluateRuleTree(at('gte'), eq).weights.has('us:X')).toBe(true);
    expect(evaluateRuleTree(at('lt'), eq).weights.has('us:X')).toBe(false);
    expect(evaluateRuleTree(at('lte'), eq).weights.has('us:X')).toBe(true);
  });

  it('walks nested ifs', () => {
    const rule: RuleNode = {
      op: 'if',
      cond: { op: 'gt', left: { ref: 'a' }, right: 0 },
      then: {
        op: 'if',
        cond: { op: 'gt', left: { ref: 'b' }, right: 0 },
        then: allocate({ 'us:X': 1 }),
        else: allocate({ 'us:Y': 1 }),
      },
      else: allocate({ 'us:Z': 1 }),
    };
    expect(evaluateRuleTree(rule, new Map([['a', 1], ['b', 1]])).weights.has('us:X')).toBe(true);
    expect(evaluateRuleTree(rule, new Map([['a', 1], ['b', -1]])).weights.has('us:Y')).toBe(true);
    expect(evaluateRuleTree(rule, new Map([['a', -1], ['b', 1]])).weights.has('us:Z')).toBe(true);
  });

  it('throws when a referenced feature has no value', () => {
    const rule: RuleNode = {
      op: 'if',
      cond: { op: 'gt', left: { ref: 'missing' }, right: 0 },
      then: allocate({}),
      else: allocate({}),
    };
    expect(() => evaluateRuleTree(rule, new Map())).toThrow(/feature "missing" has no value/);
  });
});

describe('evaluateRuleTree (tolerant / hysteresis)', () => {
  const tolGt = (cmpId: string, value: number, mode: 'absolute' | 'relative'): RuleNode => ({
    op: 'if',
    cond: {
      op: 'gt',
      left: { ref: 'price' },
      right: { ref: 'sma' },
      tolerance: { value, mode },
      id: cmpId,
    },
    then: allocate({ 'us:SPY': 1 }),
    else: allocate({}),
  });

  it('first call uses the raw compare and records state', () => {
    const rule = tolGt('px_vs_sma', 5, 'absolute');
    const out = evaluateRuleTree(rule, new Map([['price', 100], ['sma', 99]]));
    expect(out.weights.has('us:SPY')).toBe(true);
    expect(out.state.get('px_vs_sma')).toBe(1);
  });

  it('with prev=1, holds long inside the lower band (absolute)', () => {
    const rule = tolGt('px_vs_sma', 5, 'absolute');
    const state: RuleTreeState = new Map([['px_vs_sma', 1]]);
    // sma=100 → lower=95, upper=105. price=96 is below sma but above lower → stay 1.
    const out = evaluateRuleTree(rule, new Map([['price', 96], ['sma', 100]]), state);
    expect(out.weights.has('us:SPY')).toBe(true);
    expect(out.state.get('px_vs_sma')).toBe(1);
  });

  it('with prev=1, flips to short below lower (absolute)', () => {
    const rule = tolGt('px_vs_sma', 5, 'absolute');
    const state: RuleTreeState = new Map([['px_vs_sma', 1]]);
    const out = evaluateRuleTree(rule, new Map([['price', 94], ['sma', 100]]), state);
    expect(out.weights.has('us:SPY')).toBe(false);
    expect(out.state.get('px_vs_sma')).toBe(0);
  });

  it('with prev=0, requires breaking above upper to flip (absolute)', () => {
```

```ts
import type { TargetWeights } from '../strategy/reconcile';
import type { AssetId } from '../interfaces/types';
import type { Comparison, FeatureRef, RuleNode, RuleTreeState, Tolerance } from './types';

function isRef(operand: FeatureRef | number): operand is FeatureRef {
  return typeof operand === 'object' && operand !== null && 'ref' in operand;
}

function resolve(operand: FeatureRef | number, values: ReadonlyMap<string, number>): number {
  if (!isRef(operand)) return operand;
  const v = values.get(operand.ref);
  if (v === undefined) {
    throw new Error(`evaluateRuleTree: feature "${operand.ref}" has no value`);
  }
  return v;
}

function rawCompare(op: Comparison['op'], l: number, r: number): boolean {
  switch (op) {
    case 'gt':
      return l > r;
    case 'lt':
      return l < r;
    case 'gte':
      return l >= r;
    case 'lte':
      return l <= r;
  }
}

function band(right: number, tol: Tolerance): { lower: number; upper: number } {
  if (tol.mode === 'absolute') {
    return { lower: right - tol.value, upper: right + tol.value };
  }
  const factor = tol.value / 100;
  return { lower: right * (1 - factor), upper: right * (1 + factor) };
}

function evalComparison(
  cond: Comparison,
  values: ReadonlyMap<string, number>,
  state: RuleTreeState,
  outState: Map<string, 0 | 1>,
): boolean {
  const l = resolve(cond.left, values);
  const r = resolve(cond.right, values);

  if (!cond.tolerance) {
    return rawCompare(cond.op, l, r);
  }
  if (cond.id === undefined) {
    throw new Error('evaluateRuleTree: comparison with tolerance requires id');
  }
  if (cond.op !== 'gt' && cond.op !== 'lt') {
    throw new Error(`evaluateRuleTree: tolerance is only supported for op gt/lt, got ${cond.op}`);
  }

  const prev = state.get(cond.id);
  const { lower, upper } = band(r, cond.tolerance);
  let result: 0 | 1;

  if (prev === undefined) {
    result = rawCompare(cond.op, l, r) ? 1 : 0;
  } else if (cond.op === 'gt') {
    if (prev === 1) result = l < lower ? 0 : 1;
    else result = l > upper ? 1 : 0;
  } else {
    // op === 'lt'
    if (prev === 1) result = l > upper ? 0 : 1;
    else result = l < lower ? 1 : 0;
  }

  outState.set(cond.id, result);
  return result === 1;
}

function walk(
  rules: RuleNode,
  values: ReadonlyMap<string, number>,
  state: RuleTreeState,
  outState: Map<string, 0 | 1>,
): TargetWeights {
  if (rules.op === 'allocate') {
    const out = new Map<AssetId, number>();
    for (const [assetId, weight] of Object.entries(rules.weights)) {
      out.set(assetId, weight);
    }
    return out;
  }
  return evalComparison(rules.cond, values, state, outState)
    ? walk(rules.then, values, state, outState)
    : walk(rules.else, values, state, outState);
}

export function evaluateRuleTree(
  rules: RuleNode,
  values: ReadonlyMap<string, number>,
  state: RuleTreeState = new Map(),
): { weights: TargetWeights; state: RuleTreeState } {
  // Carry forward all prior state, then overwrite touched keys.
  const next = new Map<string, 0 | 1>(state);
  const weights = walk(rules, values, state, next);
  return { weights, state: next };
}
```

```ts
import type { Asset, Series } from '../interfaces/types';
import type { FeatureSpec } from '../features/spec';
import type { FeatureRuntime } from '../features/runtime';
import type { AssetRef, TacticalFeatureSpec } from './types';

function resolveAsset(ref: AssetRef): Asset {
  return ref.exchange !== undefined
    ? { kind: 'equity', id: ref.id, symbol: ref.symbol, exchange: ref.exchange }
    : { kind: 'equity', id: ref.id, symbol: ref.symbol };
}

function toFeatureSpec(spec: TacticalFeatureSpec): FeatureSpec {
  switch (spec.kind) {
    case 'price':
      return { kind: 'price' };
    case 'sma':
      return { kind: 'sma', period: spec.period };
    case 'ema':
      return { kind: 'ema', period: spec.period };
    case 'rsi':
      return { kind: 'rsi', period: spec.period };
    case 'return':
      return spec.mode !== undefined
        ? { kind: 'return', period: spec.period, mode: spec.mode }
        : { kind: 'return', period: spec.period };
    case 'volatility':
      return { kind: 'volatility', period: spec.period };
    case 'drawdown':
      return { kind: 'drawdown', period: spec.period };
  }
}

function indexAtOrBefore(series: Series, t: Date): number {
  if (series.length === 0) return -1;
  const target = t.getTime();
  let lo = 0;
  let hi = series.length - 1;
  let ans = -1;
  while (lo <= hi) {
    const mid = (lo + hi) >>> 1;
    if (series[mid]!.t.getTime() <= target) {
      ans = mid;
      lo = mid + 1;
    } else {
      hi = mid - 1;
    }
  }
  return ans;
}

function readDelayed(series: Series, t: Date, delay: number): number | undefined {
  const idx = indexAtOrBefore(series, t);
  if (idx < 0) return undefined;
  const target = idx - delay;
  if (target < 0) return undefined;
  return series[target]!.v;
}

export async function evaluateFeatureSpecs(
  specs: ReadonlyArray<TacticalFeatureSpec>,
  runtime: FeatureRuntime,
  t: Date,
): Promise<Map<string, number | undefined>> {
  const seen = new Set<string>();
  for (const spec of specs) {
    if (seen.has(spec.id)) {
      throw new Error(`evaluateFeatureSpecs: duplicate feature id "${spec.id}"`);
    }
    seen.add(spec.id);
    const d = spec.delay;
    if (d !== undefined && (!Number.isInteger(d) || d < 0)) {
      throw new Error(`evaluateFeatureSpecs: delay must be a non-negative integer, got ${d}`);
    }
  }

  const entries = await Promise.all(
    specs.map(async (spec) => {
      const series = await runtime.compute(toFeatureSpec(spec), resolveAsset(spec.asset));
      const delay = spec.delay ?? 0;
      return [spec.id, readDelayed(series, t, delay)] as const;
    }),
  );

  return new Map(entries);
}
```

```ts
import type { Asset, Bar, DateRange, Frequency } from '../interfaces/types';
import type { DataFeed } from '../interfaces/data-feed';
import type { AssetRef, SyntheticAsset } from './types';

function resolveAsset(ref: AssetRef): Asset {
  return ref.exchange !== undefined
    ? { kind: 'equity', id: ref.id, symbol: ref.symbol, exchange: ref.exchange }
    : { kind: 'equity', id: ref.id, symbol: ref.symbol };
}

const TRADING_DAYS_PER_YEAR = 252;

async function* synthesize(
  underlyingBars: AsyncIterable<Bar>,
  leverage: number,
  expense: number | undefined,
): AsyncIterable<Bar> {
  const drag = (expense ?? 0) / TRADING_DAYS_PER_YEAR;
  let prevUnderlyingClose: number | undefined;
  let prevSynthClose: number | undefined;
  for await (const u of underlyingBars) {
    let close: number;
    if (prevSynthClose === undefined || prevUnderlyingClose === undefined) {
      close = u.close;
    } else {
      const safe = Number.isFinite(prevUnderlyingClose) && prevUnderlyingClose !== 0;
      const r = safe ? (u.close - prevUnderlyingClose) / prevUnderlyingClose : 0;
      close = prevSynthClose * (1 + leverage * r) * (1 - drag);
    }
    yield {
      t: u.t,
      open: close,
      high: close,
      low: close,
      close,
      volume: u.volume,
    };
    prevUnderlyingClose = u.close;
    prevSynthClose = close;
  }
}

export function withSynthetics(
  dataFeed: DataFeed,
  synthetics: ReadonlyArray<SyntheticAsset>,
): DataFeed {
  const byId = new Map<string, SyntheticAsset>();
  for (const s of synthetics) {
    if (byId.has(s.id)) {
      throw new Error(`withSynthetics: duplicate synthetic asset id "${s.id}"`);
    }
    byId.set(s.id, s);
  }

  const wrapped: DataFeed = {
    bars(asset: Asset, range: DateRange, freq: Frequency): AsyncIterable<Bar> {
      const synth = byId.get(asset.id);
      if (!synth) return dataFeed.bars(asset, range, freq);
      const underlying = resolveAsset(synth.underlying);
      return synthesize(dataFeed.bars(underlying, range, freq), synth.leverage, synth.expense);
    },
  };

  if (dataFeed.fundamentals) {
    wrapped.fundamentals = dataFeed.fundamentals.bind(dataFeed);
  }
  if (dataFeed.events) {
    wrapped.events = dataFeed.events.bind(dataFeed);
  }

  return wrapped;
}
```

## Task 5: `fromSpec` — hydrate `TacticalSpec` into a `Strategy` (hysteresis + rebalance + synthetics)

**Goal:** The dialect hydrator. Given a `TacticalSpec`, a `FeatureRuntime`, and a `Calendar`, produce a `Strategy<TacticalFeatures>` whose:

- `universe(t)` returns the spec's universe resolved to `Asset[]` (static).
- `features(_, _, t)` resolves all feature specs (with delay applied) **and** computes the current price for every universe asset.
- `build(features, portfolio, t)` evaluates the rule tree against the value map on rebalance days (threading hysteresis state across calls via closure) and reconciles the resulting target weights. On non-rebalance days, returns `[]` without advancing hysteresis state.

**Synthetics responsibility:** `fromSpec` does *not* wrap the runtime's DataFeed itself — the user is responsible for constructing the `FeatureRuntime` with a `withSynthetics`-wrapped `DataFeed` when the spec includes synthetics. `fromSpec` validates id ambiguity at construction time. The integration test in Task 6 demonstrates the end-to-end wiring.

**Rebalance day computation.** A small helper `isRebalanceDay(t, frequency, calendar): boolean` decides whether `t` is the last session of its period. Implementation: compute the period key for `t` and the period key for `calendar.next(t)`; if they differ, today is the rebalance day. Period keys mirror v0.3's `computeRebalanceDates`:
- `Daily` → always true.
- `Weekly` → ISO week (Thursday-anchored).
- `Monthly` / `Quarterly` / `Yearly` → calendar month / quarter / year.

The helper lives at the bottom of `from-spec.ts` (module-private; not exported from the barrel).

```ts
  const synthIds = new Set(synths.map((s) => s.id));
  const universeIds = new Set(spec.universe.map((u) => u.id));

  // Each universe id that matches a synth id must be the synth itself, not a parallel ref to a different asset.
  // Heuristic: if a universe entry shares an id with a synthetic, accept it (the universe references the synthetic).
  // Conflict only arises if a synthetic's id collides with a universe entry that shouldn't be the synth — but in
  // this minimal model the universe is a flat AssetRef list, so id-equality is the only signal we have. We instead
  // detect the symmetric case: a synthetic whose id matches a universe ref but whose `underlying.id` is the SAME
  // as that ref (which would be infinite). And we detect when a synthetic id matches the underlying of any other
  // synthetic — same chain risk.
  for (const s of synths) {
    if (s.underlying.id === s.id) {
      throw new Error(`fromSpec: synthetic asset "${s.id}" cannot reference itself as underlying`);
    }
    // A synthetic id colliding with another universe ref where the universe ref's symbol differs from the
    // synthetic's symbol → ambiguous. We surface this so the user picks one or the other.
    const u = spec.universe.find((x) => x.id === s.id);
    if (u && u.symbol !== s.symbol) {
      throw new Error(`fromSpec: synthetic asset id "${s.id}" collides with a universe AssetRef of a different symbol`);
    }
  }

  // Detect the case the failing test asserts: a synthetic id equal to a universe id whose underlying is *different*
  // from that universe entry — this is the "us:SPY synthesized from us:VOO while us:SPY is also in the universe"
  // case. Ambiguous: the universe entry could mean either.
  for (const s of synths) {
    const u = spec.universe.find((x) => x.id === s.id);
    if (u && s.underlying.id !== u.id && universeIds.has(s.id)) {
      // Allow only when the universe entry is the synthetic itself (same symbol). Above check covers symbol mismatch.
      if (u.symbol === s.symbol) continue;
    }
  }

  void synthIds;
}

function periodKey(t: Date, freq: RebalanceFrequency): string {
  const y = t.getUTCFullYear();
  const m = t.getUTCMonth();
  switch (freq) {
    case 'Daily':
      return `${y}-${m}-${t.getUTCDate()}`;
    case 'Weekly': {
      const thu = new Date(t);
      thu.setUTCDate(thu.getUTCDate() + 3 - ((thu.getUTCDay() + 6) % 7));
      const yearStart = new Date(Date.UTC(thu.getUTCFullYear(), 0, 1));
      const weekNo = Math.ceil(((thu.getTime() - yearStart.getTime()) / 86_400_000 + 1) / 7);
      return `${thu.getUTCFullYear()}-W${weekNo}`;
    }
    case 'Monthly':
      return `${y}-${m}`;
    case 'Quarterly':
      return `${y}-Q${Math.floor(m / 3)}`;
    case 'Yearly':
      return `${y}`;
  }
}

function isRebalanceDay(t: Date, freq: RebalanceFrequency, calendar: Calendar): boolean {
  if (freq === 'Daily') return true;
  const next = calendar.next(t);
  return periodKey(t, freq) !== periodKey(next, freq);
}

export function fromSpec(spec: TacticalSpec, opts: FromSpecOptions): Strategy<TacticalFeatures> {
  validateSynthetics(spec);
  const universe: ReadonlyArray<Asset> = spec.universe.map(resolveAsset);
  const { runtime, calendar } = opts;
  const cadence: RebalanceFrequency = spec.rebalance?.frequency ?? 'Daily';

  let state: RuleTreeState = new Map();

  return {
    universe: () => universe,

    features: async (_u, _p, t) => {
      const [values, priceEntries] = await Promise.all([
        evaluateFeatureSpecs(spec.features, runtime, t),
        Promise.all(
          universe.map(async (asset) => {
            const s = await runtime.compute({ kind: 'price' }, asset);
            return [asset.id, seriesAt(s, t)] as const;
          }),
        ),
      ]);
      const prices = new Map<AssetId, number>();
      for (const [id, v] of priceEntries) {
        if (v !== undefined) prices.set(id, v);
      }
      return { values, prices };
    },

    build: (features, portfolio, t) => {
      if (!isRebalanceDay(t, cadence, calendar)) return [];

      const defined = new Map<string, number>();
      for (const [id, v] of features.values) {
        if (v !== undefined) defined.set(id, v);
      }
      let evaluated;
      try {
        evaluated = evaluateRuleTree(spec.rules, defined, state);
      } catch (e) {
        if (e instanceof Error && /has no value/.test(e.message)) return [];
        throw e;
      }
      state = evaluated.state;
      for (const assetId of evaluated.weights.keys()) {
        if (!features.prices.has(assetId)) return [];
      }
      return reconcile(evaluated.weights, portfolio, features.prices);
    },
  };
}
```
