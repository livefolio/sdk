# v0.4 Phase 6 — Relocate v0.3 into `parity/`

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers-extended-cc:subagent-driven-development` (recommended) or `superpowers-extended-cc:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Companion spec:** `docs/specs/2026-05-02-v0.4-phase-6-v3-relocation-design.md`

**Goal:** Move all v0.3 source from `src/` to `parity/src/v3/`. Rewrite `src/index.ts` to expose only the v0.4 surface. Bump to `0.4.0`. Update yfinance's peer-dep declaration. After this phase, `@livefolio/sdk`'s public surface is v0.4-only; v0.3 lives on as the regression target the parity gate compares against.

**Tech stack:** TypeScript (strict, `noUncheckedIndexedAccess: true`), ES modules with extensionless imports, Vitest, tsup. No new dependencies.

**Boundary already verified:** `src/{interfaces,strategy,features,tactical,reference,orders,portfolio}/` have zero imports from v0.3 modules. Only `src/backtest/simulate.ts` imports v0.3 — and `src/backtest/` itself is v0.3 (the old `simulate()`/`SimulationHandle` engine), so it moves with the rest.
