# v0.4 Phase 9 — Streaming runtime + live evaluation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-extended-cc:subagent-driven-development (recommended) or superpowers-extended-cc:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `runLive` so consumer apps can render historical backtest snapshots plus live-evaluated snapshots on a single continuous chart, with mark events that preview what the strategy would do if the current session ended now.

**Architecture:** Add a `StreamingDataFeed` interface as a sibling of the existing `DataFeed` (no rename, no union, no backward-compat alias). Promote `Strategy<F>` to `Strategy<F, S>` with `initialState()` and threaded JSON-serializable state through `build` (default `S = void` for backward compat). Refactor `fromSpec` to thread `RuleTreeState` instead of holding it in a closure — this is what makes per-tick preview-build non-destructive. Add `Crypto24x7Calendar`. Add a streaming `FeatureRuntime` mode with an append-only bar buffer. Implement `runLive` as an async generator that owns tick→bar aggregation (calendar drives session boundaries; adapters emit raw ticks) and emits a unified `AsyncIterable<LiveEvent>` with `mark` (per-tick + preview-build) and `snapshot` (per-session-close commit, identical shape to `BacktestSnapshot`).

**Tech Stack:** TypeScript (strict), Vitest, ES modules. Co-located `*.test.ts` files. Reference impls have no external deps; `runLive` uses only existing SDK primitives plus the new `StreamingDataFeed` interface.

**Spec:** [`docs/specs/2026-05-02-v0.4-phase-9-streaming-design.md`](../specs/2026-05-02-v0.4-phase-9-streaming-design.md)

## Sequencing rationale

The state API (Tasks 1–3) ships first because every later task depends on `Strategy<F, S>` being threaded through. Tasks 4 (StreamingDataFeed interface), 5 (Crypto24x7Calendar), and 6 (streaming FeatureRuntime) are independent and can ship in any order after Tasks 1–3 land. Task 7 (BacktestResult bar buffer) extends Task 2's output and feeds Task 8. Task 8 (runLive) is the big integration that consumes everything. Task 9 is the end-to-end test. Task 10 is docs.

**Backward compatibility is enforced at every task:** all existing `Strategy<F>` callers, all existing `runBacktest` callers, all existing `DataFeed` callers, and all existing tests must continue to compile and pass without changes.

  universe(t: Date, portfolio: Portfolio): ReadonlyArray<Asset>;

   * `build(features, portfolio, t): ReadonlyArray<Order>` is still accepted —
   * the runtime detects the return type at call time. New code should always

  build(

    portfolio: Portfolio,
    state: S,
    t: Date,

```

When `S = void`, callers pass `undefined` as `state` and may return either `Order[]` or `{ orders, state: undefined }`. The runtime normalizes both forms in Task 2.

```ts
export async function runBacktest<F extends Features = Features, S = unknown>(
  opts: RunBacktestOptions<F, S>,
): Promise<BacktestResult<S>> {
  const sessions = opts.calendar.sessions(opts.range);
  if (sessions.length === 0) {
    return {
      snapshots: [],
      finalPortfolio: opts.initialPortfolio,
      finalState: opts.strategy.initialState?.() as S | undefined,
    };
  }

  let portfolio = opts.initialPortfolio;
  let state: S | undefined = opts.strategy.initialState?.();
  const snapshots: BacktestSnapshot[] = [];

  for (const t of sessions) {
    const universe = opts.strategy.universe(t, portfolio);
    const features = await opts.strategy.features(universe, portfolio, t);
    const buildResult = opts.strategy.build(features, portfolio, state as S, t);

    let orders: ReadonlyArray<Order>;
    if (Array.isArray(buildResult)) {
      // Legacy state-less return shape.
      orders = buildResult;
    } else {
      orders = buildResult.orders;
      state = buildResult.state;
    }

    const fills = await opts.executor.submit(orders, t, portfolio);
    portfolio = applyFills(portfolio, fills, orders);
    snapshots.push({ t, portfolio, orders, fills });
  }

  return { snapshots, finalPortfolio: portfolio, finalState: state };
}
```

```ts
export function fromSpec(
  spec: TacticalSpec,
  opts: FromSpecOptions,
): Strategy<TacticalFeatures, RuleTreeState> {
  // ... existing validation + warnings unchanged ...
  validateSynthetics(spec);
  const universe: ReadonlyArray<Asset> = spec.universe.map(resolveAsset);
  const { runtime, calendar } = opts;
  const cadence: RebalanceFrequency = spec.rebalance?.frequency ?? 'Daily';

  return {
    universe: () => universe,

    features: async (_u, _p, t) => {
      const [values, priceEntries] = await Promise.all([
        evaluateFeatureSpecs(spec.features, runtime, t),
        Promise.all(
          universe.map(async (asset) => {
            const s = await runtime.compute({ kind: 'price' }, asset);
            return [asset.id, seriesAt(s, t)] as const;
          }),
        ),
      ]);
      const prices = new Map<AssetId, number>();
      for (const [id, v] of priceEntries) {
        if (v !== undefined) prices.set(id, v);
      }
      return { values, prices };
    },

    initialState: () => new Map() as RuleTreeState,

    build: (features, portfolio, state, t) => {
      if (!isRebalanceDay(t, cadence, calendar)) {
        return { orders: [], state };
      }

      const defined = new Map<string, number>();
      for (const [id, v] of features.values) {
        if (v !== undefined) defined.set(id, v);
      }
      let evaluated;
      try {
        evaluated = evaluateRuleTree(spec.rules, defined, state);
      } catch (e) {
        if (e instanceof Error && /has no value/.test(e.message)) {
          return { orders: [], state };
        }
        throw e;
      }
      for (const assetId of evaluated.weights.keys()) {
        if (!features.prices.has(assetId)) {
          return { orders: [], state };
        }
      }
      return {
        orders: reconcile(evaluated.weights, portfolio, features.prices),
        state: evaluated.state,
      };
    },
  };
}
```

The `let state: RuleTreeState = new Map()` declaration is gone. `state` is now a parameter to `build`, returned in the result.

import type { Asset, Bar } from './types';

/**
 * A single tick or bar update from a streaming market-data source. The bar's
 * `t` is the **arrival timestamp** of this tick — for a 24/7 source like Yahoo
 * WS, ticks arrive continuously and the runtime is responsible for deciding
 * which session/bar the tick belongs to via the `Calendar`.
 */
export type StreamingBar = {
  /** The asset this tick is for. */
  asset: Asset;
  /** The bar payload — typically a 1-tick OHLCV with `open === close === high === low === price`. */
  bar: Bar;
};

/**
 * Streaming market-data source. Sibling interface to {@link DataFeed} — they
 * are NOT a union. Historical adapters implement `DataFeed.bars()`; streaming
 * adapters implement `StreamingDataFeed.subscribe()`. A single vendor that
 * offers both (e.g. Polygon, Alpaca) implements both interfaces on one class.
 *
 * Implementations MUST guarantee:
 * - `subscribe` yields {@link StreamingBar} objects in **ascending `bar.t` order**
 *   per asset. Ordering across assets is not required.
 * - The iterable is **open-ended** — it does not terminate on its own. Consumers
 *   stop iteration by breaking the `for await` loop or by signalling cancel
 *   through whatever mechanism the runtime provides.
 * - Ticks may arrive **outside session hours** (24/7 sources like Yahoo WS).
 *   Session boundary logic is the runtime's responsibility, not the adapter's.
 *
 * @example
 * ```ts
 * import type { StreamingDataFeed, Asset } from '@livefolio/sdk';
 *
 * const feed: StreamingDataFeed = {
 *   async *subscribe(assets) {
 *     while (true) {
 *       const tick = await waitForNextTick();
 *       yield { asset: tick.asset, bar: tick.bar };
 *     }
 *   },
 * };
 * ```
 */
export interface StreamingDataFeed {
  /**
   * Subscribes to live tick updates for the given assets.
   *
   * @param assets - The instruments to subscribe to.
   * @returns An open-ended async iterable of {@link StreamingBar} updates.
   */
  subscribe(assets: ReadonlyArray<Asset>): AsyncIterable<StreamingBar>;
}
```

```ts
import type { Calendar, Session } from '../interfaces/calendar';
import type { DateRange } from '../interfaces/types';

const MS_PER_DAY = 86_400_000;

function midnightUtc(d: Date): Date {
  return new Date(Date.UTC(d.getUTCFullYear(), d.getUTCMonth(), d.getUTCDate()));
}

/**
 * 24/7 calendar where every day is a single session running midnight UTC to
 * the next midnight UTC. Suitable for crypto strategies (BTC, ETH) and any
 * always-on market.
 *
 * - `isOpen(t)` always returns `true`.
 * - `next(t)` returns midnight UTC of the day after `t`.
 * - `previous(t)` returns midnight UTC of the day before `t`.
 * - `sessions(range)` returns one Date per day in `[range.from, range.to)`.
 * - `schedule(range)` returns full Sessions with `open`/`close` at midnight UTC.
 * - `isEarlyClose(t)` always returns `false`.
 */
export class Crypto24x7Calendar implements Calendar {
  isOpen(_t: Date): boolean {
    return true;
  }

  next(t: Date): Date {
    return new Date(midnightUtc(t).getTime() + MS_PER_DAY);
  }

  previous(t: Date): Date {
    return new Date(midnightUtc(t).getTime() - MS_PER_DAY);
  }

  sessions(range: DateRange): ReadonlyArray<Date> {
    const out: Date[] = [];
    let cursor = midnightUtc(range.from);
    const end = range.to.getTime();
    while (cursor.getTime() < end) {
      out.push(cursor);
      cursor = new Date(cursor.getTime() + MS_PER_DAY);
    }
    return out;
  }

  schedule(range: DateRange): ReadonlyArray<Session> {
    return this.sessions(range).map((date) => ({
      date,
      open: date,
      close: new Date(date.getTime() + MS_PER_DAY),
    }));
  }

  isEarlyClose(_t: Date): boolean {
    return false;
  }
}

```ts
import type { Asset, AssetId, Bar } from '../interfaces/types';
import type { StreamingDataFeed } from '../interfaces/streaming-data-feed';
import type { Executor } from '../interfaces/executor';
import type { Calendar } from '../interfaces/calendar';
import type { Order, Fill } from '../orders/types';
import type { Portfolio } from '../portfolio/types';
import type { Strategy, Features } from './types';
import type { BacktestResult, BacktestSnapshot } from './run-backtest';
import { FeatureRuntime } from '../features/runtime';
import { MemoryFeatureCache } from '../reference/memory-feature-cache';
import { applyFills } from '../portfolio/apply';

/**
 * Unified event stream from `runLive`. Two variants:
 *
 * - `mark` — emitted per tick. The strategy is run in PREVIEW mode (state is
 *   snapshot/restored, no executor call, no portfolio commit). Use to render
 *   the wiggling rightmost chart point and "if the session ended now, the
 *   strategy would do X" preview UX.
 * - `snapshot` — emitted when a tick crosses a session boundary. The just-closed
 *   bar is finalized, `strategy.build` runs for real, orders are submitted to
 *   the executor, fills are applied, state advances. Same shape as
 *   `BacktestSnapshot` from `runBacktest`.
 */
export type LiveEvent<F extends Features = Features, S = unknown> =
  | {
      type: 'mark';
      t: Date;
      portfolio: Portfolio;
      prices: ReadonlyMap<AssetId, number>;
      features: F;
      previewOrders: ReadonlyArray<Order>;
      previewPortfolio: Portfolio;
    }
  | (BacktestSnapshot & { type: 'snapshot' });

export type RunLiveOptions<F extends Features = Features, S = unknown> = {
  strategy: Strategy<F, S>;
  history: BacktestResult<S>;
  dataFeed: StreamingDataFeed;
  executor: Executor;
  calendar: Calendar;
};

function snapshotState<S>(state: S | undefined): S | undefined {
  if (state === undefined) return undefined;
  if (typeof structuredClone === 'function') return structuredClone(state);
  return JSON.parse(JSON.stringify(state)) as S;
}

function midnightUtc(d: Date): Date {
  return new Date(Date.UTC(d.getUTCFullYear(), d.getUTCMonth(), d.getUTCDate()));
}

function valuePortfolio(portfolio: Portfolio, prices: ReadonlyMap<AssetId, number>): Portfolio {
  // Mark-to-market: same positions, but the implicit "value" is recomputed from prices.
  // Portfolio shape is { cash, positions } — positions are { asset, quantity }. NAV is
  // cash + sum(qty * price). Returned portfolio is structurally unchanged; consumers
  // compute NAV from positions + the mark event's `prices` map. This helper exists for
  // future when Position carries cached marketValue; for now it returns portfolio unchanged.
  return portfolio;
}

export async function* runLive<F extends Features = Features, S = unknown>(
  opts: RunLiveOptions<F, S>,
): AsyncIterable<LiveEvent<F, S>> {
  const { strategy, history, dataFeed, executor, calendar } = opts;

  // Seed streaming runtime from history.
  const featureCache = new MemoryFeatureCache();
  const runtime = new FeatureRuntime({
    mode: 'streaming',
    dataFeed: { bars: async function* () {} },  // unused in streaming mode
    featureCache,
    freq: '1d',
    initialBars: history.bars,
  });

  // Re-bind strategy to the streaming runtime if it captures one. For tactical
  // strategies this is a no-op because evaluateFeatureSpecs receives runtime
  // through fromSpec's closure — implementation detail handled by re-constructing
  // the strategy outside if needed. Default assumption: caller passes a strategy
  // already wired to a streaming runtime, OR uses a strategy whose `features`
  // method doesn't depend on a captured runtime. Document this in the recipe.

  let portfolio = history.finalPortfolio;
  let state: S | undefined = history.finalState;
  const universe = strategy.universe(new Date(), portfolio);

  // Track the current session being accumulated. Initialize from the last historical
  // session if any, else from the first tick.
  let currentSession: Date | null =
    history.snapshots.length > 0
      ? history.snapshots[history.snapshots.length - 1]!.t
      : null;
  let currentBarOpen = new Map<AssetId, number>();
  let currentBarHigh = new Map<AssetId, number>();
  let currentBarLow = new Map<AssetId, number>();
  let currentBarClose = new Map<AssetId, number>();

  function recordTick(asset: Asset, bar: Bar): void {
    const id = asset.id;
    const price = bar.close;
    if (!currentBarOpen.has(id)) currentBarOpen.set(id, price);
    currentBarHigh.set(id, Math.max(currentBarHigh.get(id) ?? -Infinity, price));
    currentBarLow.set(id, Math.min(currentBarLow.get(id) ?? Infinity, price));
    currentBarClose.set(id, price);
  }

  function finalizeBars(sessionDate: Date): void {
    for (const asset of universe) {
      const close = currentBarClose.get(asset.id);
      if (close === undefined) continue;
      runtime.appendBar(asset, {
        t: sessionDate,
        open: currentBarOpen.get(asset.id)!,
        high: currentBarHigh.get(asset.id)!,
        low: currentBarLow.get(asset.id)!,
        close,
        volume: 0,
      });
    }
    currentBarOpen = new Map();
    currentBarHigh = new Map();
    currentBarLow = new Map();
    currentBarClose = new Map();
  }

  for await (const tick of dataFeed.subscribe(universe)) {
    const tickSession = midnightUtc(tick.bar.t);

    if (currentSession === null) {
      currentSession = tickSession;
    }

    // Boundary crossed: finalize the previous session, run real build, emit snapshot.
    if (tickSession.getTime() > currentSession.getTime()) {
      finalizeBars(currentSession);
      const features = await strategy.features(universe, portfolio, currentSession);
      const buildResult = strategy.build(features, portfolio, state as S, currentSession);
      const orders = Array.isArray(buildResult) ? buildResult : buildResult.orders;
      if (!Array.isArray(buildResult)) state = buildResult.state;
      const fills = await executor.submit(orders, currentSession, portfolio);
      portfolio = applyFills(portfolio, fills, orders);
      yield {
        type: 'snapshot',
        t: currentSession,
        portfolio,
        orders,
        fills,
      };
      currentSession = tickSession;
    }

    // Record the tick into the current session's accumulating bar.
    recordTick(tick.asset, tick.bar);

    // Emit a mark event with preview-build (state snapshot/restore).
    const prices = new Map(currentBarClose);  // current "close so far" per asset
    const features = await strategy.features(universe, portfolio, tick.bar.t);
    const previewState = snapshotState(state);
    const previewResult = strategy.build(features, portfolio, previewState as S, tick.bar.t);
    const previewOrders = Array.isArray(previewResult) ? previewResult : previewResult.orders;
    // Compute hypothetical post-rebalance portfolio without actually executing.
    // For now: reuse executor.submit with a "preview" flag — but executors don't have one.
    // Pragmatic: skip executor call; previewPortfolio = applyFills(portfolio, [], previewOrders)
    // shows what the orders WOULD do if filled at current prices. Future refinement: a
    // `simulateFills(orders, prices)` helper. For Phase 9 we just expose previewOrders;
    // previewPortfolio = portfolio (unchanged) until simulateFills lands.
    yield {
      type: 'mark',
      t: tick.bar.t,
      portfolio: valuePortfolio(portfolio, prices),
      prices,
      features,
      previewOrders,
      previewPortfolio: portfolio,
    };
  }
}
```

This is a deliberate first cut. The `previewPortfolio` placeholder (returning the unchanged portfolio) is documented in the spec as "pragmatic: skip executor call." A `simulateFills` helper can ship later if consumers need accurate hypothetical post-rebalance NAVs.

# Replay-then-stream: continuous chart from history → live

This recipe shows how to render a strategy's historical performance and then continue updating the chart with live-evaluated snapshots and per-tick previews — all driven by the same strategy code.

## The shape

```ts
import {
  runBacktest, runLive,
  fromSpec, FeatureRuntime, MemoryFeatureCache, BacktestExecutor,
  Crypto24x7Calendar,
} from '@livefolio/sdk';
import type { TacticalSpec, StreamingDataFeed } from '@livefolio/sdk';

const calendar = new Crypto24x7Calendar();
const range = { from: new Date('2024-01-01'), to: new Date() };

// Set up the historical run.
const featureCache = new MemoryFeatureCache();
const dataFeed = /* your historical DataFeed */;
const runtime = new FeatureRuntime({ dataFeed, featureCache, range, freq: '1d' });

const strategy = fromSpec(mySpec, { runtime, calendar });

const history = await runBacktest({
  strategy, range,
  initialPortfolio: { cash: 100_000, positions: [] },
  dataFeed,
  executor: new BacktestExecutor({ dataFeed }),
  calendar,
  featureCache,
  featureRuntime: runtime,    // exposes bars on history.bars for runLive seeding
});

// Render history.
chart.setBars(history.snapshots);

// Continue with live ticks.
const streamingFeed: StreamingDataFeed = /* your streaming adapter */;

for await (const ev of runLive({
  strategy,
  history,
  dataFeed: streamingFeed,
  executor: new BacktestExecutor({ dataFeed }),  // or a live-broker Executor
  calendar,
})) {
  if (ev.type === 'mark') {
    chart.updateLastBar({
      t: ev.t,
      portfolio: ev.portfolio,
      prices: ev.prices,
      previewOrders: ev.previewOrders,    // "if the day ended now, strategy would do X"
    });
  } else {
    chart.appendBar(ev);                  // session-close snapshot, identical to BacktestSnapshot
  }
}
```

## Why one `Strategy` instance across both runs

Hysteresis state lives inside the strategy. `runBacktest` returns `finalState` on its result; `runLive` reads `history.finalState` and continues threading state through the live run. Pass the same `Strategy` instance to both — the state API ensures continuity.

## Why mark events show "what would happen at close"

`runLive` runs `strategy.build` for every tick in PREVIEW mode (state is snapshotted before the call and restored after). The result is the orders the strategy would emit if the session closed at the current tick price. This is the data behind a "freeze the bar at close" UX where the rightmost bar wiggles until the session ends.
